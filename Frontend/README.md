# Para.tn — AI-Powered Parapharmacy Platform

**Para.tn** is an intelligent platform that connects customers with multiple parapharmacies in Tunisia. It uses artificial intelligence to analyze facial images, identify potential dermatological conditions, and recommend relevant skincare products. The platform also integrates geolocation to help users discover nearby parapharmacies.

## ✨ Features

- 🤖 **AI Skin Analysis:** Detect potential dermatological conditions using deep learning and computer vision.
- 🧴 **Smart Recommendations:** Suggest skincare products based on AI analysis results.
- 📍 **Geolocation:** Find nearby parapharmacies based on the user's location.
- 🏪 **Multi-Parapharmacy:** Explore products from different parapharmacies.
- 👥 **Management System:** Manage users, products, and platform operations.

## 🛠️ Technologies

- **Mobile:** Flutter & Dart
- **Frontend:** React
- **Backend:** Node.js & Express.js
- **AI Service:** Python & Flask
- **Database:** MongoDB
- **Deep Learning:** EfficientNetB0

## 🧠 AI Module — IntelFaceAssis

Uses deep learning to analyze facial images and classify supported skin conditions, helping provide personalized skincare product recommendations.

## ⚠️ Disclaimer

AI predictions are for informational purposes only and do not replace professional medical diagnosis.
